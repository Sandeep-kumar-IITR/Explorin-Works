# ExplorIN Coursework Archive

A collection of data-science exercises and course work. The repository contains notebooks, datasets, topic folders and an archived project bundle.

This is a learning archive rather than one standalone application. Individual folders may have their own instructions and dependencies.

## Working with the material

- Open notebooks in Jupyter.
- Check the source and licence of each dataset before reuse.
- Install dependencies based on the imports in the notebook being run.
- Keep credentials and personal data out of notebooks and exported files.

The archive is retained for reference. It is not part of the main project portfolio.
